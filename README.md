# Responsive Portfolio Website

## Project Overview

This project is a responsive portfolio website recreated from the reference designs provided for the assignment.

The website includes a home page, blog section, work/projects section, and project details. It is designed to work on both desktop and mobile screen sizes.

## Technologies Used

- HTML5
- CSS3

## Website Pages

### Home Page
Includes the introduction, profile image, recent posts, featured works, navigation, and footer.

### Blog Page
Displays a list of blog posts with their titles, dates, categories, and descriptions.

### Work Page
Displays the projects with their images, titles, categories, and descriptions.

### Project Details Page
Displays detailed information and images for a selected project.

## Responsive Design

The website adapts its layout to different screen sizes, including desktop and mobile devices.
